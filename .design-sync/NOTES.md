# design-sync notes — kalasy.ai

## Repo shape

- This is a Vite website, not a packaged library: no `main`/`module`/`exports`, `dist/` is the compiled site. Do NOT run `npm run build` for the sync — it builds the website. The bundle entry is the committed barrel `.design-sync/ds-entry.js` (`cfg.entry`); a synthesized entry would drop the sections' `export default`s (`export * from` doesn't re-export defaults).
- All 19 components are pinned in `cfg.componentSrcMap` (no `.d.ts` exists, so pinning is the discovery mechanism, not an enumeration smell). The 9 icons all live in `src/components/Icons.jsx`.
- Every component reads the `LangProvider` i18n context (`useLang()`); previews crash without `cfg.provider = {component: "LangProvider"}`.

## Sync plumbing (all regenerated by `cfg.buildCmd` = `node .design-sync/gen-content-shims.mjs`)

- `src/i18n.jsx` imports `../content/be.md?raw` / `en.md?raw` (Vite `?raw`) — plain esbuild can't resolve those. Fix: `.design-sync/tsconfig.json` (`cfg.tsconfig`) maps the exact specifiers onto generated shims in `.design-sync/.cache/content-shims/`.
- `Hero.css` references `url("/assets/bg-hero.jpg")` (absolute site path) — same tsconfig-paths trick maps it to a generated 1×1 PNG so esbuild resolves; the real photo comes back via `cfg.cssEntry`.
- `cfg.cssEntry` = generated `.design-sync/.cache/styles-entry.css`: inlines `src/styles/global.css` (only `main.jsx` imports it, the bundle never sees it) + data-URI overrides restoring the three `/assets/*` images (hero bg downscaled to 1600px, hosts 900px, favicon 128px via macOS `sips` — re-sync on non-macOS would need a different downscaler). The gen script asserts Hero.css's gradient text still matches what it embeds and fails loudly if the background changed.
- Fonts (Unbounded, Golos Text, Marck Script, Bad Script) are Google Fonts loaded via `<link>` in `index.html`; the bundle ships them itself: `.design-sync/fetch-fonts.mjs` (one-time, re-runnable) downloaded latin+cyrillic woff2 subsets into committed `.design-sync/fonts/`, wired via `cfg.extraFonts`.
- Docs: `.design-sync/docs/<Name>.md` (`cfg.docsDir`), frontmatter `category` groups the picker into Sections/Icons.

## Preview conventions

- Sections are designed for the dark body — every preview wraps in `<div style={{background:'var(--night)'}}>`. Cards render on white otherwise.
- `Header` is `position:fixed`: preview wrapper uses `transform: translateZ(0)` to become its containing block, plus `cfg.overrides.Header = {cardMode:"single"}` (was flagged `[GRID_OVERFLOW]` escape).
- Icons are unsized `currentColor` SVGs — previews size them via `style` and use the site's brand colors from `Platforms.jsx`.
- `Episodes` fetches remote RSS at runtime but ships `FALLBACK_EPISODES`, so it renders statically.
- Language stories: only `be` (default) is previewed; switching to `en` needs localStorage/user interaction — not statically renderable per-story.

## Re-sync risks

- **Content drift is handled** (shims/styles regenerate from `content/*.md`, `global.css`, `public/assets/*` via buildCmd) — but the **hero gradient** is duplicated in `gen-content-shims.mjs`; the script fails loudly on drift, fix it there.
- **`.design-sync/tsconfig.json` maps exact import specifiers** — if `i18n.jsx` renames/adds content files or `Hero.css` changes the image path, the mapping (and gen script) must be updated; esbuild resolution errors will point at it.
- **Fonts are a snapshot**: if the site's `index.html` font list changes, re-run `.design-sync/fetch-fonts.mjs` (it re-fetches from the css2 URL embedded in it — update weights there too).
- **`sips` (macOS-only) in gen-content-shims.mjs** — re-syncing on Linux/CI needs an ImageMagick/sharp replacement for the downscale step.
- **`conventions.md` enumerates class/token names** — validated against the build on 2026-08-01; re-validate the names on each re-sync per the base skill.
- Only partially verified: `Featured`'s YouTube iframe renders as an embed in headless Chromium; inside claude.ai/design a CSP could block it (card would show an empty frame — component itself is fine).
